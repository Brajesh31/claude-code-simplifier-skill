# Code Simplifier

A focused code refinement skill for improving clarity, consistency, and maintainability while preserving behavior.

## What it does

- Simplifies recently changed code within the requested scope.
- Removes unnecessary complexity, duplication, and confusing structure.
- Follows existing project conventions and architecture.
- Preserves public behavior, edge cases, and error semantics.
- Verifies changes with relevant tests and static checks.

## Usage

Use when cleaning up code, refactoring for readability, or reviewing recent changes for maintainability. The skill avoids broad rewrites and does not optimize for fewer lines at the expense of clarity.

## Safety

Review the diff before accepting changes. Do not remove important behavior, alter unrelated files, or claim verification that was not performed.
